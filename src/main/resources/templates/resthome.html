Surveys by ID

Method: GET Endpoint: /api/survey/{id}

JSON Example: 

    
{
  "_links": {
    "self": {
      "href": "http://localhost:8080/api/surveys/1"
    },
    "survey": {
      "href": "http://localhost:8080/api/surveys/1"
    }
  },
  "name": "Survey1",
  "description": "Survey description"
}

Answers by ID

Method: GET Endpoint: /api/answer/{id}

JSON Example: 

    
{
  "_links": {
    "self": {
      "href": "http://localhost:8080/api/answers/1"
    },
    "answer": {
      "href": "http://localhost:8080/api/answers/1"
    },
    "question": {
      "href": "http://localhost:8080/api/answers/1/question"
    }
  },
  "answer": "En tiiä mikä",
  "type": null
}
